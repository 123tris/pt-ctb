# Names in the forum threads → osu! ids

Every name as written in the five Top 10 threads (2020, 2021, 2022, 2023-24, 2025), with the osu! user id used in the
edition files and the account's username today (November 2026).

**Sources:**
- **Author link:** the user id on a post's author link.
- **Post link:** a profile link inside someone's post (ExPin's and tartaruga57's 2023-24 lists and ExPin's 2025 list link every name).
- **Profile:** `osu.ppy.sh/users/<name or id>`, which also resolves previous usernames and lists them.
- **Index:** `players.json` from data.ptcatch.com.
- **Text:** what the posts themselves say.

The osu! API wasn't used.
